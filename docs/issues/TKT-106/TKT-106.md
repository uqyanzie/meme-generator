# TKT-106: Unresponsive "Pay Now" Button Without Feedback

- **Execution Order:** 6
- **Layer:** Frontend (+ Backend verification)
- **Status:** Open
- **Related Tickets:** [TKT-105](../TKT-105/TKT-105.md)

---

## Summary

Clicking "Pay Now" (Bayar Sekarang) on the checkout page produces no UI feedback, state change, or confirmation when processing or failing.

## Reported Behavior

Clicking "Pay Now" multiple times results in no button state change, no loading indicator, no success or error message, and no receipt/confirmation, leaving the user unsure whether the payment was processed.

## Expected Behavior

The payment action must immediately reflect a loading state (disabling duplicate clicks), display clear success confirmation or actionable error feedback if payment confirmation fails, and never silently swallow errors.

## Potential Impact

Users cannot complete or verify payments, leading to repeated clicks, confusion, and lost conversions.

---

## Initial Codebase Touchpoints

- `web/src/app/checkout/[reference]/page.tsx`:
  - `onPay` swallows all errors in `catch {}`.
  - Button lacks `disabled={confirm.isPending || Boolean(confirm.data)}` and loading label.
  - No error UI rendered when `confirm.isError` is true.
- `api/internal/modules/subscription/handler.go` & `repository.go` (`Confirm` / `ConfirmPayment` — verify happy path, double-confirm behavior, and error responses).
