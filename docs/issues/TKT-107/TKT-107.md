# TKT-107: Unauthorized Viewing and Deletion of Other Users' Memes (IDOR)

- **Execution Order:** 7
- **Layer:** Backend
- **Status:** Open
- **Related Tickets:** Unblocks `ResultUpload` flow for [TKT-108](../TKT-108/TKT-108.md) and [TKT-109](../TKT-109/TKT-109.md)

---

## Summary

Users can view, modify, and delete memes belonging to other users by manipulating the meme ID in the request URL.

## Reported Behavior

By changing the meme ID in the URL, a user was able to view and delete another user's meme.

## Expected Behavior

All meme read, upload-result, complete, and delete endpoints must enforce strict ownership checks (`WHERE id = $1 AND user_id = $2`), ensuring users can only access, update, or delete their own memes.

## Potential Impact

Critical security vulnerability (Insecure Direct Object Reference / IDOR) enabling unauthorized data access, tampering, and destruction.

---

## Initial Codebase Touchpoints

- `api/internal/modules/meme/repository.go`:
  - `GetByID(ctx, id, userID)` omits `AND user_id = $2` **and** selects 10 columns (`updated_at`) into 9 `Scan` arguments (runtime scan bug!).
  - `SetResultURL(ctx, id, userID, resultURL)` omits `AND user_id = $3`.
  - `Delete(ctx, id, userID)` omits `AND user_id = $2`.
- `api/internal/modules/meme/mount.go` & `handler.go` (audit all meme routes and check whether a single-meme `GET` endpoint exists or needs ownership verification).

---

## Pending Decisions (Discuss Before Implementation)

- [x] **HTTP status for unauthorized resource access:** Return `404 Not Found` (`ErrNotFound` / `CodeMemeNotFound`) via `WHERE id = $1 AND user_id = $2` (standard IDOR defense preventing resource enumeration, single atomic query).
- [x] **S3 object cleanup on delete:** Enforce DB ownership (`DELETE FROM memes WHERE id = $1 AND user_id = $2 RETURNING base_url, result_url`) **plus** best-effort S3 object cleanup (`DeleteObject` for base and result keys in Garage S3 after DB deletion, logging errors without failing the response).
- [x] **Single-meme `GET /api/v1/memes/{id}` scope:** Keep existing routes only (audit confirms no `GET /api/v1/memes/{id}` exists; fix `GetByID` for `ResultUpload`, plus `SetResultURL` and `Delete`).
